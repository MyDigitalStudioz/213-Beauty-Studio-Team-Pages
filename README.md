## How it works

- The studio homepage (`MyDigitalStudioz/213-Beauty-Studio`) has a Meet the Experts directory. In the sold version, each expert's card links to **her page here first** — her name, her work, her services and prices — and her page links out to the booking system she already uses (GlossGenius / Acuity / Instagram). Nothing about how she books changes.
- Every worker page is the **same template**: hero (name + specialty + Book button) → about → portfolio gallery → service menu with starting prices/durations → booking policies → rating highlight → "Find me at 213 Beauty Studio" (address, studio hours, directions, back-link to the studio page) → footer.
- To add a worker: copy an existing worker folder, swap name, accent color, services, prices, photos, and booking URL. That's the whole job.
